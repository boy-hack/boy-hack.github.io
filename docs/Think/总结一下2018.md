# 总结一下2018

在 https://x.hacking8.com/archive.html 可以很容易看到博客发布的文章和时间，在2018年几乎每个月几乎都发布了帖子，https://x.hacking8.com/t/ 也记录了一年的感想。发现自己是越来越喜欢写博客了~ 

##  回顾 

  * 1月份发布emlog大前端4.8，更新了w9scan 
  * 2~3月份，w10scan和w8scan的想法，但是两个都没有实现出来，想法计划几乎都有了，最后还是没有写出代码 
  * 4月，做c++ Opengl游戏课的课程设计 
  * 5~6月，学校的事情和帮别人实现了zscan初版 
  * 7~8月，北京实习，参加kcon,w11scan和hack-requests的发布，入手mac 
  * 9月，自建网络空间引擎初步的想法，创建airbug漏洞poc收集计划，在freebuf上发表了一篇公开课 
  * 10月，玩单片机幻想鼓捣一个机器人，sqlmap源码学习，制定了“成为黑客的5年计划”。 
  * 11~12月，知道创宇实习，学习各类黑客源码，自建网络空间引擎命名为w12scan并列为毕业设计计划。 



##  All in all 

看了各类源码之后，知道自己差在哪里了，在造轮子的过程中，前面百分之八十都是简单的，而后面百分之二十才是困难的，甚至超过前面百分之八十，这百分之二十的代码取决于你的想法思路和眼界。 

虽然大部分东西都是丢一个想法在那，想法谁都有的，我现在写代码的目的就在于是否是自己需要的，如果不是必须要的，可能这个想法的实现优先级在D之后了。优先实现我所需是我的宗旨，但是我需要什么？好像还比较模糊，全自动的漏洞扫描?…
