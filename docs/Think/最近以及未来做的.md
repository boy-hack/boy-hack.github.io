# 最近以及未来做的

不知道为什么，我很喜欢隔一段时间就写篇总结性的文章，总结一下近期状况和未来要做的。

## 最近

首先我发现当初无意写的w9scan的在github已经获得快500个赞了，这非常让我高兴，也加大了我开源的热情~但是是我创造的w9scan,我也很明白w9scan的弊端，扫描功能很弱，各种小bug很多，甚至我现在连他的代码结构都觉得不行，为此我也曾列出了各种修改计划甚至计划重写，但这些都躺在文字上。

> 因为懒吗

emlog大前端的更新计划已经发布一个月了，却还是没有想要写代码的念头，也是很懒。这很难想象，当初代码还不精时，一个html样式可以让我兴致勃勃的调试一天，但是现在让我看十分钟都觉得多余。现在相比以前，在代码方面我觉得提高了很多，但恰恰是提高了这么一点（其实还是什么都不会），我却一点都没有写的欲望了。

现在的版本能用就好了，这就是我现在的想法。不知道为什么，写到这里，我心中的“不爽”好像消散了些。又仔细想了想，应该是技术方向的问题吧，之前写的w8scan、w9scan等等的扫描器让我欣喜若狂，恨不得马上写完，现在再看这些都索然无味，是不是这些技术方向不再吸引到我了？

最近在帮一个公司写一款扫描器，内部代号为`zscan`，在技术可行性上面没有问题，所有功能都是我之前做过的，有的东西调试一番也能运行，问题是做到最后的时候，每写一行代码，似乎总有一种东西在阻止你，这种感觉非常不好受。这也让我在思考，让兴趣成为职业是否是对的？成为职业后可能会把兴趣消耗殆尽，再也找不到其中的乐趣了。可能这也是我现在这么讨厌写代码的原因吧？

最近其实就两件事情让我比较在意，一个是在freebuf上上线了视频教程，本想增加一下“睡后收入”，但是关注度似乎很少，我觉得我讲的是“安全开发”，网上此类教程很少应该很受关注才对啊？但是关注的人确实很少。二是面试长亭被拒了，之前在实习的时候，有一副天下我最牛逼的感觉，但是这一拒又让我重新思考人生了，仔细一想想，自己也确实没有什么可“牛逼”的地方啊。

就是这两件事让我重新思考了一下人生，其实也是和我现在大四比较浮躁有关，对，我终于找到了一个词来形容我的状态了，**浮躁** 啊浮躁。

## 未来

最近的一个新闻引起了我的关注，一名“黑客”在Singapore因未授权渗透某酒店时被抓，我看了这篇博客的渗透过程以及攻击手法，我觉得“黑客”就当如此啊，有着对一切的好奇心，then hack it,这是我最羡慕的状态啊，而且他才23岁。

最近也看了很多人的博客，大家年龄和我差不多，却都辣么优秀，令人羡慕的优秀啊，我想说你们能不能学慢点啊，我快学不动了 /(ㄒoㄒ)/~~

我发现写博文还是有不少好处的，写这些之前我的心情很低落，但是写到这里，我突然想通了什么，感到无比的舒畅~

我就是要成为一名“黑客”，而`写代码`可以当做一种职业，似乎这两种也不冲突。

## How to do

既然未来我的`战略方针`已经制定,当然一切都围绕这个战略方针进行。

  * 先把`zscan`写完，感觉它的存在束缚了我做其他事情。
  * 补补基础知识，在长亭的面试里有很多基础知识，但是都说不出来，我深知自己的基础知识还是很薄弱，但是看的话可能会睡着，刷刷CTF来补知识，我觉得这个可以。以战养战！
  * 把之前的坑填完，什么emlog大前端更新完，w9scan该重写重写！之前的计划该完成完成。
  * sqlmap阅读计划，朋友让我写一本关于sqlmap的书，虽然没说完成时间，但是看完sqlmap源码我觉得对我不管是写软件还是做黑客都是至关重要的！



这些我估计完成就需要很多时候了，到时候我的又一个`五年计划`估计又出现了，所以先按照现在的规划一步步完成先吧！
