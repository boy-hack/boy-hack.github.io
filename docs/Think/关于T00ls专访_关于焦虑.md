# 关于T00ls专访

刚刚把w12scan完成了，但心里却越来越焦虑，那么说说我的想法吧。

## 关于T00ls专访

在年前有幸得到了T00ls的专访(https://www.t00ls.net/articles-49732.html) 和进入名人堂的资格，这让我很高兴，同时也充满担忧与焦虑。专访是在2018年暑假实习期间联系我的，当时豪情万丈意气风发，因为当时w11scan完成，参加kcon，期间和各路大佬谈笑风生，再加上T00ls的专访，更是喜上加喜，所以谈话间会带有一股自豪，颇有一种谈笑间樯橹灰飞烟灭的气势。在得到专访后，我想，一不做二不休，也进入名人堂吧~查看了进入名人堂的条件，分析后有一项是发帖要满多少个，当时自己离要求差了一两百，T00ls是不允许刷帖和水贴的，所以当时在小本本上制定了一个计划，每天发5回复，都是找些自己的擅长领域回复，当时是八月份，按照计算，每天回复后到11月就可以满足条件了。我真这么做了。

所以五个月后得到T00ls专访和名人堂我也不太惊讶，当初的激动现在也没有什么，好像就和寻常事一般。

## 关于焦虑

以前做技术完全因为兴趣，可能一点皮毛就因此开心，但现在不一样，现在因为工作，你不能再因为你的兴趣而选择性的学习，跳过繁文缛节那段，必须把技术的前因后果吃透，也就是说在现代社会的分工体系下，必须专精一门技术，所以这个时候学习必然是痛苦的，学习也不会拥有满足感，因为你知道必须经过痛苦的学习才能学会，收益和期望是可预见的，过程是痛苦的，当然不会觉得开心。

同时，可能在别人眼中，你是大佬，大神，优秀的人，其实我认为这是捧杀，我认为自己达不到这种称呼。从大学开始我就一直受到这样的称呼，开始还乐滋滋，后面就觉得这就像是一种侮辱。自己可以拿去作对比，自己会的语言在别人眼里根本算不了什么，自己能在一两天内学会语法别人就不能吗，在v2ex上，在公司里，自己的这些优势根本不值一提。优势如果比不上，弱点就会无限放大。

同时新技术变化之快可能难以想象，以前我还难以想象为什么360在几乎垄断PC机杀毒时代拼命开启其他领域，作搜索，作浏览器等等，没想到两年之后移动时代来临，PC时代很快就消失了。我依然记得10年的时候有人问比特币是骗局吗，知乎上众多赞同声音，认为是一个骗局，此时有人说骗局不骗局我不知道，但是聪明人都在玩这个。我们都自以为是认为自己是聪明人吗？也很难想象，前几年暴火的比特币现在已经完全消失了。在我眼里，比特币只是验证了密码学在程序中的重要作用。

总的说来还是要突破自己的舒适区，一个技术你玩的很熟练了，即进入了舒适区，以我个人的经历来说，突破是困难的。我也有很强的拖延症，我了解我每学一个新技术当时的状态都是无比难受，而且越是想快点掌握，心中焦虑感便更强。

## 关于w12scan

w12scan便是突破舒适区的一种尝试，对于django，只是停留在语法层面，现在用它完成了一个项目，再被它各种设置恶心的同时也体会了它的便好。对于Elasticsearch更甚，出现的各种问题中文几乎没有，有时候出现的错误要一天时间排查，阅读各种英文文档，比较满意的是这些问题都解决了。

w12scan开源在了github，当初的愿想是解决shodan、zoomeye、fofa的限制，同时兼顾批量刷漏洞的效果，原本想部署在vps上自用，但是学生机的vps内存不够，跑不动（主要是elasticsearch），最终放弃了自用部署。原以为开源后会大受欢迎（没有人开源过）但却鲜有问津…虽然我github上快接近600粉丝了。我也很不明白这是为什么。其实我也不在意是否有人会给我提pr，但是关注量这么少，却是我纳闷的原因。是宣传没做好？是部署困难？是没有用？

## 关于生活

我是喜静的人，但有时候也想在平静的生活里泛起片片水花。沉迷技术时总是忽略了生活，生活的仪式感是很重要的。

## 结

  1. 对目前的成就表示祝贺，但后面的挑战依然巨大
  2. 舒适和非舒适是永恒对立的，也许某个节点之后就想从舒适跳到非舒适，某个节点又跳回来了，我想在技术范围里，做好规划，一步一步按照规划运行就行了。新年看了电影《飞驰人生》，赛车是爱好，也是一场马拉松，技术也是如此，在马拉松中，不是突然有个什么技巧就能改变的，是少犯错，多做。
  3. 对于w12scan最后一个功能，节点的监控日志我决定还是做完，无论w12scan未来如何，也无论我的愿景是否能达到，它完成了，开源了，足以。
  4. 我确立了在生活上重点培养的爱好，写字和写作，虽然目前技术上的研究依然占据了更多的时间，这和一个公司转型另一个主要方向一样，转变的过程是痛苦的，不能求快，慢慢就好。
