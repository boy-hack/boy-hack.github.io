# 毕业后的中秋

毕业的第一个中秋，短短的两天，刚刚结束了与同学的聚会，站在公交站台，心有所想。几年前的我们，是站在公交站台等待着归去学校的公交，看着开来的一辆辆熟悉的公交，却都不是我等待的那一辆，因为通过导航得知我坐的是一辆陌生的公交回到住的地方，而不是那些熟悉的公交回到学校了。 
    
朋友说，短短四年，一瞬间就过去，感觉也没有感觉到特别的记忆，或许十年后也会感慨，毕业十年，也没有特别的记忆。我说到，所以趁现在就要做些值得记忆的事情啊，是啊，朋友附和道。随后过了两三秒，我又说到，道理我们都懂啊，随后相视一笑，沉默了下来。 
    
虽然只是三四人的小聚会，我们也聊到班上哪些人去了哪里，哪些人做了什么，还有哪些人留在武汉。聊到技术，计科系毕业的我们说的最多的是前端，是后端，是安全，是数据库，是运维，大家都有一份看上去体面的工作，但又在各自的对比中诉说着自己的不满，想着如何努力学习变得更好。我发现一个有趣的现象，对自己需求更多的人更想着努力学习变得更好，对自己需求比较少的人更享受当下的生活，两种情况我认为都很好，都挺羡慕，并没有鄙视的意思。我是属于第一类，但看了几个朋友的生活方式和生活状态，也让人羡慕不已。 
    
中秋也和朋友在蹦床馆体验了一下，两个小时的时间感觉已经将我一年的运动量完成了，这种折腾自己的事情，虽然很痛苦，但我还是很乐意的，唯一的遗憾就是，还是没能克服恐惧，不敢跳太高，一些项目不敢玩。 
    
但我还是认为生命在于折腾的（趁年轻的时候），一次不行，有机会就在去几次。还是希望自己能够懂得生活，享受生活。技术上面，我想先将知识整理到hacking8上，同时完善w13scan这个项目，以及继续探究自动化刷SRC的实践。
